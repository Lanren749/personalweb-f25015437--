# KB-03 班次交接与异常处理

> 来源：排期与培训协调员访谈、交接模板核对、质量复核要求（合成演练）
> 版本：v0.4（2026-11-19）

## 交接单四类必填项

班次交接单必须包含四类内容，缺任意一类不得完成交接：

1. 未完成事项：具体库位、单据号、剩余数量、卡在哪一步；
2. 设备与工具：PDA、扫描枪、叉车钥匙、对讲机等数量与状态；
3. 异常与风险：设备故障、货物破损、安全事件、客户临时要求；
4. 确认人：交班组长与接班组长双方具名，记录确认时间。

禁止用"已交接""没问题""收到"等模糊表述替代具体内容。交接单必须能回答"哪一项、多少、在哪、谁确认"。

## 责任转移时点

责任从接班组长具名确认时转移，不以群消息发送时间为准。未完成具名确认前，交班方仍对未交接事项负责。系统记录确认人、确认时间与操作 IP 或设备标识，作为审计凭证。

## 交接完整性判定

交接完整 = 四类必填项均非空 + 确认人存在 + 未完成事项包含库位或单据号。任何一项不满足，系统状态保持"待交接"，不得进入"已交接"。

抽查规则：质量复核每周抽查不少于 2 个班次的交接单；发现漏项，退回并记录责任人。连续两周完整率低于 100% 时，暂停试点扩大。

## 常见异常处理

| 异常 | 处理方式 | 是否升级 |
| --- | --- | --- |
| 无证人员被安全员劝离 | 立即停止作业，记录事件，通知服务顾问补人 | 是，2 小时内 |
| 培训记录缺失 | 标记待核实，不得默认放行，补录后复核 | 是，班前会前 |
| 人员与名单不符 | 以门禁与身份证件核对，禁止口头替换 | 是 |
| 交接漏项 | 接班方拒绝签字，退回交班方补齐 | 否，但计入考核 |
| WMS 接口中断 | 启用纸质名单与电话确认，事后补录 | 是 |
| 客户临时改需求 | 生成新版本需求单，评估是否超过 24 小时红线 | 是 |

## 停机与转人工原则

系统在以下情况必须停止自动建议并转人工：证书状态不明、培训记录缺失、数据时间戳超过 7 天、需求变更超过 24 小时红线、接口中断。转人工必须有接收人、时限和升级路径，不能只弹提示。

## 事件复盘模板

每起异常记录五要素：时间、班次、岗位、直接原因、根因、责任人、纠正措施、是否需修改规则。复盘结论进入知识库，形成下一轮规则更新的输入。
